# 邀请内测

查房公开。邮件提醒首批向 5 个邮箱开放，每人最多 2 条；不需要注册账户。邀请制控制参与规模，不能解决 Cloudflare 免费档的单次 CPU 超限，因此首版仍属于试用。

## 初始化与分发

完成数据库迁移后，运行一次：

```bash
npm run invites -- --remote
```

本地开发使用 `npm run invites`。工具只使用官方 Wrangler 和 Node 内置模块，不发送邀请邮件。

邀请码明文保存在被 Git 忽略的 `.data/invitations.json`，权限为 `0600`；云数据库只保存 SHA-256 摘要。终端只显示数量与文件路径。请自行从该文件复制邀请码给受邀者，不要提交或公开整个文件。

已有验证邮箱优先占用创始成员名额，保留原提醒与管理链接。当前拥有者占 1 名，其余 4 个码可以分发。初始化不会重新启用暂停提醒，也不会发送邮件。重复运行复用同一批邀请码；私有文件丢失时不能从摘要恢复，不要盲目重建或轮换。

## 受邀者流程

1. 打开网站查房，建立提醒时填写邮箱与邀请码。
2. 收到验证邮件后，在网页主动确认启用。
3. 使用专属管理链接暂停、恢复、修改、取消或建立第二条提醒。

一个邀请码只绑定一个验证邮箱。未验证的占位在 30 分钟后释放；邀请码初始有效期 90 天。已绑定成员通过有效管理链接继续使用，不依赖邀请码期限。

待验证、启用和暂停提醒占个人名额；已取消或到期的提醒释放提醒名额。取消全部提醒不释放成员身份，不能用同一个码邀请另一个邮箱。

## 开发配置

生产 `wrangler.json` 配置 `INVITATION_REQUIRED=true`、`REMINDERS_PER_EMAIL=2`、`REMINDERS_TOTAL_LIMIT=10`。邀请模式由服务端验证，不依赖网页输入框；没有有效邀请码或已绑定成员的管理凭据时，不能建立提醒或排验证邮件。管理邮件请求返回统一提示，避免公开成员邮箱。

已有验证和管理链接保留兼容。数据库迁移只添加邀请表和关联字段；既有暂停状态不变。
